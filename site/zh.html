语音输入，不必绕道云端。

很多语音输入只是网页服务外面套了一个麦克风按钮。VocoType 是真正的 Linux 输入法：在本地录音、识别，并把文字直接提交到当前应用。

01 / 隐私

不上传任何数据

FunASR Paraformer 在本机完成识别；声音、草稿和输入框上下文都无需离开设备。

02 / 原生

几乎处处可用

聊天窗口、编辑器、浏览器、终端与 AI 工具，都通过 Linux 输入法框架接收文字。

03 / 实用

为 CPU 设计

面向普通 Linux 台式机与笔记本优化，内存占用适中，不要求独立显卡。

边界清晰的本地流水线

从按下按键，到文字进入输入框。

每个阶段只承担明确职责。可选的语言模型润色位于语音识别之后，也可以完全关闭。

01

按住说话

按住 F9 开始说话，内容说完后松开按键。

02

录音与 VAD

本地采集音频，并通过语音活动检测提取有效语段。

03

本地 ASR

FunASR Paraformer 在 CPU 上识别中文和中英混合语音。

04

提交文本

IBus 或 Fcitx 5 把最终结果写入当前获得焦点的应用。

桌面框架集成

沿用你本来就在使用的 Linux 输入栈。

两个前端共享同一套语音识别核心，同时分别遵循各自输入法框架的原生协议。

IBus

完整支持

适合 GNOME，以及默认采用 IBus 的 Linux 发行版。

  • Python 输入法引擎
  • 极速与润色听写
  • 基于输入框上下文的语音编辑

Fcitx 5

完整支持

适合 KDE，以及偏好模块化 Fcitx 5 生态的用户。

  • C++ Addon + Python 后端
  • 极速与润色听写
  • 独立安装路径，可与 IBus 共存

从源码安装

选择输入法框架，然后开口说话。

安装脚本会配置后端、输入法集成和模型选项。IBus 与 Fcitx 5 两个版本可以同时安装。

IBusGNOME / 默认输入栈
$ git clone https://github.com/LeonardNJU/VocoType-linux.git
$ cd VocoType-linux
$ ./scripts/install-ibus.sh
$ ibus restart
Fcitx 5KDE / 模块化输入栈
$ git clone https://github.com/LeonardNJU/VocoType-linux.git
$ cd VocoType-linux
$ bash fcitx5/scripts/install-fcitx5.sh
$ fcitx5 -r

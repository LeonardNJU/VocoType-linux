SHIPPEDJUL 2026

Desktop setup

One graphical settings center replaces manual setup.

VocoType now gives IBus and Fcitx 5 users the same graphical installation and repair workflow. The window keeps environment choices, downloads, build output, and errors in one place, while desktop Polkit dialogs handle the few operations that require system privileges.

SHIPPEDJUL 2026

Supportability

Doctor turns “it does not work” into actionable evidence.

The new diagnostics flow checks Python, dependencies, models, Fcitx modules, IBus components, services, IPC sockets, configuration, terminology, microphones, and ITN. Users can then create a redacted support bundle or open a prefilled GitHub issue from the same window.

RESEARCH

True streaming speech recognition

Move beyond “record, release, then transcribe.” While the user is speaking, VocoType should display a mutable preedit whose earlier words may be revised as later audio changes the posterior distribution.

This is distinct from the streaming AI-polish preview already implemented for Fcitx 5.
